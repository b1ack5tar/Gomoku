# 弈星五子棋

一个基于原生 HTML、CSS、JavaScript 实现的单页五子棋网页游戏，使用 Canvas 绘制棋盘，支持休闲对局和比赛对局两种模式。

这个项目本身没有复杂背景，主要是闲着无事时让 AI 顺手写的，一个用来刷刷 commit、也顺便验证多 Agent 协作体验的小项目。实际使用的 Agent 组合是 `OpenCode + Codex + Claude Code`。

## 项目特点

- 原生前端实现，无框架、无构建工具
- 15 x 15 标准五子棋棋盘
- 黑棋先手，自动判定胜负与平局
- 支持棋谱记录与最新落子高亮
- 支持显示/隐藏手数
- 休闲对局支持悔棋
- 比赛对局支持局时与读秒
- 关键操作带确认弹窗，避免误触
- 适配桌面端和移动端浏览器

## 对局模式

### 休闲对局

- 不启用正式计时
- 可以悔棋
- 适合演示、练习和复盘

### 比赛对局

- 每局初始局时为 `10:00`
- 局时耗尽后进入 `30` 秒读秒
- 读秒剩余 `10` 秒内会高亮提醒
- 黑棋第一手落下后开始计时
- 比赛模式下禁用悔棋

## 运行方式

项目是纯静态页面，直接启动一个本地 HTTP 服务即可。

```bash
cd gomoku
python3 -m http.server 8000
```

浏览器访问：

```text
http://localhost:8000
```

## 主要交互

- 单击棋盘空位落子
- `显示手数`：切换棋子上的落子编号
- `悔棋`：仅休闲模式可用
- `重新开始`：重置当前对局
- `休闲对局 / 比赛对局`：切换模式；若对局进行中，会先弹出确认框

## 规则说明

- 黑棋先行，双方轮流落子
- 任意方向连续五子即可获胜
- 棋盘下满且无人连成五子则判为平局
- 比赛模式中，当前行棋方读秒耗尽则判负

## 实现说明

- 棋盘、棋子、星位、手数、最后一手高亮均由 Canvas 绘制
- 棋谱坐标采用 `A-O` 列、`15-1` 行表示法，例如中心点为 `H8`
- 计时器基于 `setInterval` 实现
- 弹窗为单一复用组件，通过按钮文案和回调切换不同场景
